## 3. Implementation Consistency and Discrepancy Analysis

A rigorous comparison between the initial design specifications (`DDL.sql`, `ERD.drawio`), database scripts, and the actual C# implementation revealed several notable implementation decisions and nuances:

### 3.1 Database Naming
- In `DDL.sql`, the database creation statement uses `Create Database DLVD; use DlVD;`.
- In `dbSettings.cs`, the active connection string uses `Database=MyDVLD;`. Developers deploying the database must ensure the database is restored or created with the name `MyDVLD` or update `dbSettings.cs`.

### 3.2 Person Demographic Columns
- The initial `DDL.sql` defined: `FirstName`, `SecondName`, `LastName`.
- In `Views.sql` and the BLL/DAL classes (`abPerson.cs`, `clsAddNewPerson.cs`, `clsFindPersonBy.cs`), a fourth name field (`ThirdName`) was added to support standard four-part Arabic naming conventions. In the database, `ThirdName` is nullable.

### 3.3 Symmetric Password Encryption vs. Hashing
- While security best practices typically dictate one-way hashing (e.g., bcrypt or Argon2) with per-user salting for passwords, the actual codebase implements **reversible AES-256 symmetric encryption** (`clsEncryptDecrypt`).
- Rationale: The system requires decrypting the password when reading from `C:\DVLDSavedLoginInfo\SavedLogin.json` to auto-populate the password textbox in `frmLogin`.

### 3.4 Retake Test Fee Lookup Nuance
- In `clsRetakeTest.cs` (lines 32), the constructor contains:
  ```csharp
  RetakeTestApplication?.PaidFee =
      clsApplicationTypes.FindAppObjByAppID((int)clsApplicationTypes.enApplicationTypes.RenewDrivingLicense).ApplicationFees;
  ```
  In `ApplicationTypes`, both `RenewDrivingLicense` (ID 2) and `RetakeTest` (ID 7) have identical fees of $5.00 in the seeded data, resulting in the correct monetary charge, though technically referencing the Renew enum key instead of `RetakeTest`.

### 3.5 License Validity Duration
- In `DDL.sql`, `LicenseClasses.DefaultValidityLength` represents duration in years (e.g., 5 or 10 years).
- In `clsLicenses.cs` (line 43), the expiration date is computed using:
  ```csharp
  this.ExpirationDate = IssueDate.AddMonths(clsLicenseClasses.FindLicenseClassByID(LicenseClassID).DefaultValidityLength);
  ```
  This is a verifiable implementation detail where `AddMonths` is called with the numeric value from `DefaultValidityLength`.
